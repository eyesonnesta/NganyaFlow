# NganyaFlow short demo

1. Start the server per README. Check /health and /api/v1/meta (demo_mode=true).
   Read role codes privately from server/runtime/demo-access-codes.txt.
2. Install/open APK, Explore without contributing, choose Muthaiga/direction.
   Explain the wait RANGE, bar, route badge, freshness, crowding and Demo data chip.
   Browse Routes, open a route diagram and About this estimate.
3. Scroll the stage board to boarding. Explicitly consent, choose route237 (none is
   preselected), review, save. Activity distinguishes saved locally/Queued from Synced.
   Use Sync now if Android delays background work. Open the report to show Undo.
4. Settings > Field team and crew: enumerator code, observation workspace. Choose
   Muthaiga,237,towards town; Start a PRACTICE session. Record three synthetic test
   arrivals with crowding. Show open vehicles and event log. Sync and verify on server.
   Mark missing departures UNOBSERVED, then End session; never invent a departure.
5. Field team and crew: Sign out, crew code, Open crew demand. Choose237,60min and
   expand Muthaiga. Compare app reports, arrivals, crowding, limited-data status and
   wait availability. These are participating riders, never total passengers.
6. Settings: language, appearance, data/privacy. After showing crew counts, delete the
   demo report data with confirmation. Activity empties and deletion completes on sync.
7. Wait alerts: stage/route/direction/threshold, grant notification permission in context,
   enable one alert. A current upper range bound <= threshold triggers one notification.
   It opens Stage. Cancellation, replacement and two-hour expiry prevent old alerts.

Rapid synthetic test arrivals can fall outside the forest training support. The correct
result is then No estimate, with a reason. Do not fabricate timestamps to force an
estimate. The live simulator supplies supported examples and resumes after session close.
For a physical phone, use an existing HTTPS tunnel, paste its URL into server Settings,
and close it afterward. No tunnel was started for this delivery.
